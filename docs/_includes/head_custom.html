Just the Docs builds a dark stylesheet next to the light one but gives every visitor the light one; theme.js adds the dark one on top, for a device set to dark or for the choice made with the button in header_custom.html, before the page paints. Without JavaScript the noscript copy follows the device. Only on screen: a page prints light.
