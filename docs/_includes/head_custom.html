{%- comment -%} The dark theme (#272). Just the Docs builds a dark stylesheet next to the light one but gives every visitor the light one; theme.js adds the dark one on top, for a device set to dark or for the choice made with the button in header_custom.html, before the page paints. Without JavaScript the noscript copy follows the device. Only on screen: a page prints light. The preload fetches the dark stylesheet for a dark device alongside the light one, not only once theme.js has run after the theme's own scripts. It can't see the button's choice: a dark device whose visitor chose light still fetches it early, and a dark choice on a light device fetches it only once theme.js runs (usually from the cache by then). dark_media is the dark device's query for all three: the preload, the noscript copy, and theme.js (data-dark-media). {%- endcomment -%} {%- assign dark_css = '/assets/css/just-the-docs-dark.css' | relative_url -%} {%- assign dark_media = 'screen and (prefers-color-scheme: dark)' -%}
