Create an admin account

This one-time setup creates the admin account that protects Backuparr's web UI.

There's no email recovery. If you forget the password, click Reset Backuparr on the login screen - it wipes all local state (config, connections, backups) and brings you back here.

Save your encryption key

This key encrypts the passwords, API keys and cloud logins Backuparr stores, and Backuparr's own backup. You need it to restore Backuparr after losing this server.

It's the key set with BACKUPARR_SECRETS_KEY.

Save it in a password manager, or Backuparr can't be restored.
